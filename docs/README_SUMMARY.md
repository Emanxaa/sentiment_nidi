# Ringkasan Repositori Thesis-LSTM-IndoBERT

Repositori ini berisi implementasi tesis untuk klasifikasi sentimen tweet banjir di Sumatera menggunakan tiga pendekatan model: LSTM, BiLSTM, dan IndoBERTweet-LoRA. Repositori juga mencakup analisis topik dengan BERTopic, TF-IDF, dan LDA.

## Tujuan Utama
- Melakukan preprocessing teks tweet berbahasa Indonesia
- Membangun model sentimen (LSTM, BiLSTM, IndoBERTweet-LoRA)
- Menganalisis topik sentimen menggunakan BERTopic, TF-IDF, dan LDA
- Membandingkan performa model dengan data empiris dan data simulasi
