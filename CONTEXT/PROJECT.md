# Project Context

## Research

Evaluate LSTM performance on Indonesian flood sentiment classification under imbalanced data.

Dataset:

* processed_text_v2
* 8648 rows
* 3 classes

Data split:

* Train 80%
* Test 20%
* Stratified
* Validation = 10% of Train

Primary metric:

* Macro F1

Secondary:

* Accuracy
* Precision
* Recall

Every experiment must use the same architecture.

Only balancing strategies change.
