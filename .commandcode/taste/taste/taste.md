- When asking a question, wants a direct answer first ("jawab dulu") — the assistant should answer before proposing or doing any implementation, and follow-up offers should come after the answer. Confidence: 0.6

Confidence: 0.9

Confidence: 0.85

- Asks for written guides ("bisa berikan guide bagi saya?", "buat panduan ... dari cli") and expects the guide to be delivered as a reusable markdown file in the project `docs/` folder — with quick-reference commands per phase, configuration, from-scratch workflow, troubleshooting table, and output locations — not just a chat explanation. Confidence: 0.8
